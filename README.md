# Baskaran Clinic

Production-ready, mobile-first website for **Baskaran Clinic**, Melur, Madurai.

## Stack
- Next.js 14 (App Router) · React · TypeScript
- Tailwind CSS · Lucide React · Framer Motion

## Run locally

```bash
cd baskaran-clinic
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build && npm start
```

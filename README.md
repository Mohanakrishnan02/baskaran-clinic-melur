# Baskaran Clinic — Melur

The clinic Melur loves. Mobile-first Next.js site for **Baskaran Clinic**, Alagar Kovil Road, Melur.

## Live links
- **GitHub:** https://github.com/Mohanakrishnan02/baskaran-clinic-melur
- **One-click Vercel deploy:** [Import this repo on Vercel](https://vercel.com/new/clone?repository-url=https://github.com/Mohanakrishnan02/baskaran-clinic-melur)

## Local test

```bash
cd baskaran-clinic
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Production build check:

```bash
npm run build && npm start
```

## Deploy on Vercel (free preview URL)

1. Open: https://vercel.com/new/clone?repository-url=https://github.com/Mohanakrishnan02/baskaran-clinic-melur  
2. Sign in with GitHub → **Deploy**  
3. You get a URL like `https://baskaran-clinic-melur.vercel.app`

Or via CLI (after `npx vercel login`):

```bash
npx vercel --prod
```
